# Backend Development Study Topics

This document outlines the core topics and technologies to study for mastering backend development.

## 1. Programming Languages
- [ ] **Go (Golang):** Concurrency (Goroutines, Channels), Performance.
- [ ] **Python:** Django, FastAPI, Flask.
- [ ] **JavaScript/TypeScript:** Node.js, Express, NestJS.
- [ ] **Java:** Spring Boot, JVM.
- [ ] **Rust:** Safety, Performance.

## 2. Databases
### Relational (SQL)
- [ ] PostgreSQL (Advanced features, JSONB)
- [ ] MySQL
- [ ] SQL Fundamentals (Joins, Indexing, Transactions, ACID)

### Non-Relational (NoSQL)
- [ ] **Document:** MongoDB
- [ ] **Key-Value:** Redis (Caching, Pub/Sub)
- [ ] **Wide-Column:** Cassandra
- [ ] **Graph:** Neo4j

## 3. API Design & Communication
- [ ] **REST:** Principles, HTTP methods, Status codes.
- [ ] **GraphQL:** Queries, Mutations, Schemas.
- [ ] **gRPC:** Protobuf, Streaming.
- [ ] **WebSockets:** Real-time communication.
- [ ] **Webhooks:** Event-driven updates.

## 4. Web Servers & Proxies
- [ ] **Nginx:** Reverse proxy, Load balancing, SSL termination.
- [ ] **Apache**
- [ ] **Caddy**

## 5. Security
- [ ] **Authentication:** JWT, Session-based, OAuth2, OpenID Connect.
- [ ] **Authorization:** RBAC (Role-Based Access Control), ABAC.
- [ ] **Encryption:** Hashing (bcrypt, Argon2), HTTPS/TLS.
- [ ] **OWASP Top 10:** SQL Injection, XSS, CSRF, etc.

## 6. Architecture Patterns
- [ ] **Monolithic**
- [ ] **Microservices:** Service discovery, API Gateways.
- [ ] **Serverless:** AWS Lambda, Google Cloud Functions.
- [ ] **Event-Driven Architecture:** Pub/Sub, Event Sourcing.

## 7. Caching
- [ ] **Client-side:** Browser caching.
- [ ] **Server-side:** Application level.
- [ ] **Distributed Caching:** Redis, Memcached.
- [ ] **CDN:** Cloudflare, Akamai.

## 8. Message Brokers & Queues
- [ ] **RabbitMQ**
- [ ] **Apache Kafka**
- [ ] **Redis Streams**

## 9. DevOps & Infrastructure
- [ ] **Containerization:** Docker.
- [ ] **Orchestration:** Kubernetes.
- [ ] **CI/CD Pipelines:** GitHub Actions, GitLab CI, Jenkins.
- [ ] **Infrastructure as Code (IaC):** Terraform, Ansible.
- [ ] **Monitoring & Logging:** ELK Stack (Elasticsearch, Logstash, Kibana), Prometheus, Grafana.

## 10. Testing
- [ ] **Unit Testing**
- [ ] **Integration Testing**
- [ ] **End-to-End (E2E) Testing**
- [ ] **Load & Performance Testing**
